# Аналитика ликвидации - Страница участника Flisi

## 📋 Описание страницы

Страница аналитики ликвидации для участника **Flisi** в системе ДАВС. Предназначена для фиксации и отслеживания временных меток процессов ликвидации происшествий.

## 🎯 Функциональность

### 1. **Временные рамки ликвидации**
- Установка даты и времени начала ликвидации
- Установка даты и времени окончания ликвидации

### 2. **Управление процессами**
- Добавление новых процессов
- Фиксация времени начала и окончания каждого процесса
- Описание каждого этапа работ

### 3. **Причина задержки**
- Текстовое поле для указания причин, повлиявших на сроки ликвидации

### 4. **Сохранение данных**
- Кнопка "Сохранить" выводит все введенные данные в консоль браузера

### 5. **Диаграмма Ганта**
- Заглушка для будущей визуализации процессов

## 🛠 Технологии

- **React** - библиотека для построения пользовательского интерфейса
- **React Hooks (useState)** - управление состоянием компонента
- **CSS-in-JS** - стилизация компонентов
